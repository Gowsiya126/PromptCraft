🚀 PromptCraft – Agentic AI Prompt Engineering Studio

Turn simple instructions into clear, structured, and optimized prompts!

📌 About the Project

PromptCraft is a Python-based Prompt Engineering Studio designed to improve the quality of user prompts through a multi-agent workflow.

It analyzes user input, structures the prompt, evaluates its quality, and suggests improvements through four connected agents.

🎯 Problem Statement

Many users write unclear or incomplete prompts, which can lead to poor AI responses. PromptCraft helps solve this problem by transforming basic instructions into more organized and effective prompts.

✨ Key Features

- 🔍 Prompt Analyst: Identifies missing information in user prompts.
- 🏗️ Prompt Architect: Structures prompts into meaningful sections.
- 📊 Prompt Evaluator: Evaluates prompt quality and provides a score.
- ⚡ Prompt Optimizer: Improves prompts by adding missing details.
- 📚 13 Prompt Engineering Techniques: Includes role prompting, few-shot prompting, chain prompting, and more.
- 🖥️ Interactive Interface: Built using Streamlit.

🤖 Multi-Agent Workflow

1. User enters a basic prompt.
2. Prompt Analyst examines the input.
3. Prompt Architect creates a structured prompt.
4. Prompt Evaluator checks prompt quality.
5. Prompt Optimizer improves the prompt.
6. Final evaluation displays the result.

⚙️ Installation and Setup

Step 1: Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the project folder

cd PromptCraft

Step 3: Create a virtual environment

python -m venv .venv

Step 4: Activate the environment (Windows)

.venv\Scripts\activate

Step 5: Install dependencies

pip install -r requirements.txt

Step 6: Run the application

streamlit run app.py
